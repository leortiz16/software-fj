# software-fj
Sistema de gestión de clientes, servicios y reservas con POO en Python, con interfaz gráfica en Tkinter y sin base de datos.

## Ejecución
python software_fj_gui.py

## Archivos
- software_fj_gui.py: código completo (clases, excepciones, logs e interfaz)
- eventos.log: se genera al ejecutar el programa
